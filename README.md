\# Healthcare Readmission Risk Pipeline (PySpark + Machine Learning)



\## Overview

This project builds an end-to-end data science pipeline to predict 30-day hospital readmission risk using PySpark, SQL analytics, and machine learning.



The system simulates real-world healthcare analytics workflows, including ETL pipelines, feature engineering, predictive modeling, and API deployment.



\---



\## Key Features



\- PySpark ETL pipeline for large-scale data processing

\- Spark SQL analytics for business insights

\- Machine learning model (Random Forest)

\- ROC-AUC: 0.86

\- FastAPI deployment for real-time predictions
